# @relay/contract

The shared contract: the schema of the results model
([docs/results-model.md](../../docs/results-model.md)) and its types, used
both by `relay-engine` (which produces them) and by the apps (which read
them).

A single source of truth for the shape of results, versioned with the rest:
that is what the monorepo protects.
